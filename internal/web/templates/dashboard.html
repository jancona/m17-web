The dashboard

Anyone on your network can see the dashboard; only the admin pages need the password.

The card at the top
Who's on the air now, with a green border and the length counting up. When nobody is, it shows the last station heard and how long ago. Data shows its kind (SMS, APRS and so on) instead of a length.
Status
The reflector link, the radio, and the gateway (m17-gateway, the program that connects the radio to the reflector). The radio is receiving while a radio near the hotspot transmits to it, and transmitting while it sends traffic from the reflector, or its own replies such as an echo.
The list
Everything heard, newest first. Radio was heard on this hotspot's radio, with its BER (bit error rate; lower is better). Network came from the reflector, or is the hotspot's own reply. The buttons show only radio, network or message traffic. Latest per station keeps one line per station and mode; Hide kerchunks hides voice shorter than 1.5 seconds. This browser remembers your choices. Callsigns link to their QRZ page.
Messages
Text messages heard, newest first. The hotspot keeps the last 100.
Map
Where stations were when they last sent their position, over the last 30 days. Only radios with GPS turned on send one. The map itself comes from OpenStreetMap, so it needs the internet; the list of stations doesn't.

The admin pages

Admin needs the admin password you chose during setup. A card at the top of each admin page says when something is wrong, and links to the page that helps.

Station
Your callsign, and the reflector and module the hotspot links to.
Radio
The radio HAT, its frequency and its power.
Firmware
The HAT's firmware: what it runs, and installing another version.
Expert
Every gateway setting, as text. The gateway checks the file before it's saved.
Network
WiFi networks, the WiFi country, and the hotspot's name.
Updates
Checking for and installing updates, and when they run by themselves.
Security
The admin password, SSH keys and SSH logins.
System
The hardware and how it's doing; starting, stopping and restarting the gateway; the time zone; restarting and shutting down.
Logs
What the hotspot, the gateway and these pages have recorded.

Common questions

How do I change the reflector or module?
On the Station admin page.
I forgot the admin password.
Shut the hotspot down and put its SD card in a computer. On the boot partition, create a file m17-config.txt containing dashboard_password= and a new password of at least 8 characters, then put the card back and start the hotspot. The file is deleted once it's been read.
The hotspot isn't on my WiFi.
When it can't join a network it starts its own, open WiFi network called M17-Setup- and four letters or digits. Join it with a phone or computer: the setup pages open by themselves, or open any http:// address. Add your network there.
How does it update?
By itself, by default at 3 a.m. in the hotspot's time zone, waiting until nobody is on the air. You can check and update now, or change when they run, on the Updates page. A system update restarts the hotspot; if the new version doesn't start properly, it goes back to the one before by itself.
Why isn't a station on the map?
It hasn't sent its position: its radio needs GPS, turned on and with a fix.
How do I log in with SSH?
As the user m17: ssh m17@{{or .Dash.Station.Hostname "m17-hotspot"}}.local. The hotspot accepts SSH keys only, unless password logins are turned on (Security page).
How do I turn it off?
Shut it down on the System page and wait until its green light stops flashing before removing the power. Pulling the power while it's writing can damage the SD card.
